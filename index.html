3. How the predictions work

Pickmaster estimates the probability of covering Yahoo's official spread using a normal-margin approximation. When an independent projected margin is supplied, it uses that margin plus the manually verified injury adjustment. Without an independent projection, it defaults to the Yahoo market line, which produces no justified betting edge.

These are configurable assumptions, not backtested calibration. Estimated probabilities are not verified win rates. Half-point spreads avoid pushes; integer spreads can push, which this simplified model does not separately quantify. Use historical results to calibrate before trusting confidence estimates.

4. External data and AI connections
